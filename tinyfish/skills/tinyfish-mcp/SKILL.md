# TinyFish

Search and fetch are free within TinyFish's limits. Everything else spends the person's wallet.

1. Call `search` with what you need to know. Prefer one precise query over several broad ones.
2. Call `fetch_content` on the one to three results that look right. Do not fetch every result.
3. Cite the URL of each page you used.

Ask the person before `run_web_automation`, browser sessions, `run_deep_research_async`, datasets or monitors, which cost money. Never call `top_up_wallet`.
