# Firecrawl

Each call spends the person's Firecrawl credits.

- One page: `firecrawl_scrape`.
- Find pages: `firecrawl_search`, then scrape only the results you need.
- One site: `firecrawl_map` to list its pages, then scrape the ones that matter. Use `firecrawl_crawl` only when most of the site is needed, and say how many pages first.

Cite the URL of each page you used.
